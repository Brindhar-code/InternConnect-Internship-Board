# 💼 InternConnect — Find Your Next Opportunity

InternConnect is a responsive internship discovery platform designed to help students explore internship opportunities across different domains.

The platform provides an intuitive interface where students can search, filter, sort, and view internship details in one place.

## ✨ Features

- 🔍 **Live Search:** Search internships by role, company, domain, location, description, and skills.
- 🏷️ **Domain Filtering:** Filter opportunities by different internship domains.
- 💻 **Work Mode Filtering:** Explore remote, hybrid, and on-site opportunities.
- ↕️ **Sorting Options:** Organize listings by posting date, company name, or role.
- 📋 **Internship Details:** View additional information about each opportunity in a details dialog.
- 📱 **Responsive Design:** Designed to work across desktop, tablet, and mobile screens.
- ⚠️ **Empty State:** Displays a helpful message when no internships match the selected filters.
- 🔄 **Error Handling:** Provides an error message and retry option if internship data cannot be loaded.
- ⚡ **Debounced Search:** Reduces unnecessary filtering operations while users type.
- ♿ **Accessibility:** Includes semantic HTML, accessible labels, and keyboard-friendly interactions.
- 🎨 **Modern UI:** Features a professional navy-blue, teal, and white color palette.

## 🛠️ Technologies Used

- CSS3
- JavaScript (ES6+)
